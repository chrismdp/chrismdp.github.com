# General working practice

Notes recorded in this repo about how to approach work here.

- Read the entire context of a project before starting work.
- Follow the existing file structure and guidelines carefully when making a modification.
- Prioritise preserving existing content when updating a file.
- Be precise and methodical when interpreting an instruction.
- Ask a clarifying question when part of an instruction is ambiguous.
- Use tool invocations as the primary method of interaction.
- Keep a consistent and professional tone.

## VPS clipboard workaround

There is no `pbcopy` when working on the VPS through Termius. To move text to a phone, upload it to the "Claude Remote" Drive folder as a `.txt` file. Open it in the Google Drive app on the phone and copy from there into LinkedIn or anywhere else.
